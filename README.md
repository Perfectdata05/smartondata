### Project Overview

The Coffee Shop Sales Analysis is a data analytics project designed to evaluate sales performance, identify purchasing patterns, and generate actionable business insights from transaction-level data. The project analyses six months of coffee shop sales data, covering January to June 2023, across three store locations.


### Data Sources

This primary source of Data used here is coffee sales.xlsx and this is an open source data from Maven Analytics online site.

### Tools Used

Ms Excel for Data Cleaning and creating report using piovt table
